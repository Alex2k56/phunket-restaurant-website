A sleek, fully responsive, and performance-optimized front-end website created for **Phunket Restaurant**, an authentic dining establishment. The application delivers an engaging digital experience for customers featuring interactive menu exploration, smooth navigation, table reservation handling, and mobile-first responsiveness.

---

## 🌟 Key Features

- **📱 Mobile-First Responsive Design:** Seamless user experience across all viewports (mobile, tablet, desktop).
- **🍽️ Interactive Food Menu:** Dynamic filter tabs allowing users to explore starters, main courses, desserts, and beverages.
- **📅 Table Reservation System:** Interactive client-side reservation form with real-time validation.
- **⚡ Fast Performance & Smooth Scrolling:** Optimized assets, semantic markup, and zero unnecessary external heavy dependencies.
- **🎨 Modern UI/UX Architecture:** Clean layout, elegant color palette, custom micro-interactions, and accessible navigation.

## 🛠️ Tech Stack & Methods

- **Frontend:** HTML5, CSS3 (Flexbox, CSS Grid, Custom Variables), JavaScript (ES6+)
- **Architecture:** BEM (Block Element Modifier) methodology for modular and scalable CSS.
- **Icons & Fonts:** FontAwesome / Google Fonts (Inter / Playfair Display)
